A problem found with one particular scale packet, phone or situation is fixed by a rule that holds
in general, never by a check that recognises that one case.

**Why:** learned in rubikki-solveri (user 2026-10-12: "no striped-cube fix, something that helps
generally"); the user asked to carry rubikki's lessons over (2026-11-08).

**How to apply:** state the general weakness first, design the fix for it, use the odd case as a
test, and check the fix on every other recorded case too.
