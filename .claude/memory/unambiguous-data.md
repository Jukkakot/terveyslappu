Every chart, number and list must be read in one way only, with as little room for a wrong
reading as possible. Many of the user's requests follow from this: units always shown
(show-units-everywhere), weight scale fitted so differences show (fit-weight-scale), same unit on
one shared scale (shared-unit-axis: on overlaid bars with two kcal scales, the taller bar could be
the smaller value — misleading).

**Why:** the user (2026-11-16) said the point of these changes is how a person interprets the
data; two scales for one unit made bars look the wrong way round. They expected me to infer the
Allekkain answer from that.

**How to apply:** before asking a chart/number question, ask "which option can be misread?" and
pick the one that cannot; ask only when both are equally unambiguous. Flag anything elsewhere in
the app that could mislead (same unit on different scales, missing units, truncated axes without
a cue) as a backlog suggestion.
